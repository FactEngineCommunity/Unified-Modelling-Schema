## Model once. Use everywhere.

Unified Modelling Schema captures both data structure and meaning in one portable model. Use the same schema across relational, graph, document, and multi-model systems.

<CardGrid stagger>
	<Card title="Start with the model" icon="pencil">
		Define types, portable properties, keys, constraints, relationships, and their natural-language readings in one YAML document.
	</Card>
	<Card title="Keep the semantics" icon="document">
		Fact type readings make the intended meaning explicit for people, generated documentation, and AI-assisted work.
	</Card>
	<Card title="Choose your target" icon="seti:database">
		Use the same UMS model when designing relational tables, property graphs, document structures, or a mixed estate.
	</Card>
	<Card title="Find your paradigm" icon="open-book">
		The reference explains how UMS concepts translate for relational, graph, document, and multi-model practitioners.
	</Card>
</CardGrid>

export const umsExample = `Types:
  - Type: Person
    Labels:
      - Person
    PrimaryKey:
      - Person_Id
    Properties:
      - Name: Id
        DataType: Integer
        Constraints:
         - NOT NULL
         - UNIQUE
        FactTypeReadings:
         - Language: English
           Readings:
            - Person has Id
            - Id is for Person
      - Name: LoginName
        DataType: TextVariableLength
        Constraints:
         - NOT NULL
         - UNIQUE
        FactTypeReadings:
         - Language: English
           Readings:
            - Person has LoginName
            - LoginName is of Person

      - Name: Name
        DataType: Text`
