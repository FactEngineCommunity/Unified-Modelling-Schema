Questions about the Unified Modelling Schema, its purpose, structure, and use.

## About UMS

<details>
<summary>What is the Unified Modelling Schema?</summary>

The Unified Modelling Schema is a portable semantic schema for describing data structures, relationships, constraints, and natural-language meanings across multiple data models.

</details>

<details>
<summary>Why does UMS include natural-language predicates?</summary>

Natural-language predicates preserve the meaning of model elements in a form that can be understood by people and used by AI systems.

</details>

## Data Models

<details>
<summary>Which data models does UMS support?</summary>

UMS is intended to describe relational, property graph, document, fact-based, and multi-model structures.

</details>

<details>
<summary>Can the same schema be used for relational and graph databases?</summary>

Yes. A UMS schema can preserve a common semantic model while supplying mappings appropriate to different implementation targets.

</details>

## Using UMS

<details>
<summary>What format is UMS written in?</summary>

UMS uses a portable text-based representation designed to be readable by people, software tools, and AI systems.

</details>

<details>
<summary>Can I generate database schemas from UMS?</summary>

Yes. One of the intended uses is generation or transformation into target database schemas and related artefacts.

</details>
